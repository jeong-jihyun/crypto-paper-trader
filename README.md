# crypto-paper-trader

실제 거래소 앱과 같은 화면으로 연습하는 **코인 모의투자 앱**입니다. 진짜 돈은 쓰지 않고, 가상 원화(기본 1,000만원)로 사고팔면서 연습합니다.

## 주요 기능
- **거래소**: 원화마켓 전체 시세 목록 (검색, 정렬, 관심 ★, 보유 필터)
- **코인 상세**: 캔들 차트(1분~주), 호가창, 내 평균 매수가 표시
- **주문**: 지정가 / 시장가, 호가 단위(＋/−), 수수료 0.05%, 주문 확인창
- **미체결**: 지정가 주문 대기·취소, 가격이 닿으면 자동 체결
- **투자내역**: 보유자산, 평가손익, 확정손익, 거래내역
- **연습 미션 6개** + 용어 가이드(시장가·지정가·호가·미체결 등)

## 시세 출처
업비트 공개 API(키 없음, 무료)를 서버 라우트로 받아 쓰고, 실패하면 빗썸 공개 API로 대신합니다.

## 실행
```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 매매 엔진 테스트
```

## 구조
- `lib/trade.mjs` : 매매 엔진 (시장가 호가 소진 체결, 지정가, 미체결, 평가). 화면과 분리되어 테스트 가능
- `app/page.js` : 화면 전체 (거래소 / 투자내역 / 더보기, 코인 상세)
- `app/api/market/route.js` : 전체 시세
- `app/api/coin/route.js` : 한 코인의 호가 + 캔들
- `test/trade.test.mjs` : 엔진 테스트

## 알아둘 점
- 주문은 이 앱 안에서만 가상으로 체결됩니다. 기록은 브라우저(localStorage)에 저장됩니다.
- 미체결 주문은 앱을 열어 둔 동안에만 체결 여부를 확인합니다.
- 실제 거래소와 체결 방식·수수료·호가 단위가 조금 다를 수 있습니다.
- 연습용이며 실제 투자 결과를 보장하지 않습니다.
